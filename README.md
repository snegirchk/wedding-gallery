# Хранилище фото и видео со свадьбы

Открытый общий альбом: любой гость по ссылке может загрузить свои фото и видео,
посмотреть галерею с превью, скачать отдельный файл или всё архивом.
Файлы лежат в Cloudflare R2 сколько угодно долго.

Дизайн — в стиле пригласительного (палитра navy + cream, акварельный фон,
шрифты Cormorant / EB Garamond / Marck Script).

## Что внутри

```
public/index.html          галерея + загрузка (весь UI)
public/admin.html          модерация: список + удаление (по секретному слову)
functions/api/upload.js     загрузка файла целиком (< 88 МБ) и превью
functions/api/mpu.js        multipart-загрузка больших видео
functions/api/list.js       JSON-список файлов для галереи
functions/api/file/[[path]].js  отдача файла из R2 (+ Range для видео, ?dl=1 — скачать)
functions/api/zip.js        потоковый ZIP «скачать всё»
functions/api/admin/delete.js   удаление файла
wrangler.toml               привязка R2-бакета
```

Сборки нет — чистый HTML/JS + Cloudflare Pages Functions.

## Локальный запуск

```bash
cd wedding-gallery
npm install
cp .dev.vars.example .dev.vars      # при желании поменяйте ADMIN_SECRET
npx wrangler pages dev
```

Откроется `http://localhost:8788`. Локально R2 эмулируется в папке `.wrangler/`
(файлы никуда не улетают). Проверьте: загрузку фото и видео, галерею, лайтбокс,
`/api/zip`, и `admin.html#<секрет>`.

## Деплой на Cloudflare (бесплатно)

Нужен аккаунт Cloudflare (тот же, где пригласительное).

1. **Создать R2-бакет**
   - Dashboard → R2 → *Create bucket*, имя, например `wedding-gallery`.
   - Если имя другое — впишите его в `wrangler.toml` → `bucket_name`.
   - Для R2 нужно один раз включить R2 в аккаунте (карта нужна для верификации,
     в пределах бесплатного лимита ~10 ГБ хранения списаний нет).

2. **Создать проект Pages и задеплоить**
   ```bash
   npx wrangler login
   npx wrangler pages deploy
   ```
   При первом запуске wrangler спросит имя проекта (например `wedding-gallery`)
   и создаст его. Дальше каждый `wrangler pages deploy` обновляет сайт.

   Либо через Dashboard → Pages → подключить Git-репозиторий,
   *Build output directory* = `public`.

3. **Привязать бакет к Pages**
   - Pages → проект → *Settings* → *Bindings* → *Add* → *R2 bucket*
   - Variable name: `BUCKET`, бакет: `wedding-gallery`
   - (то же самое уже прописано в `wrangler.toml`, но для Pages-проекта
     привязку надо подтвердить в настройках — и для Production, и для Preview)

4. **Задать секрет модерации**
   - Pages → *Settings* → *Variables and Secrets* → *Add*
   - Имя `ADMIN_SECRET`, тип *Secret*, значение — любое слово/фраза.
   - После этого админка: `https://ваш-сайт.pages.dev/admin.html#ваша-фраза`

5. **(по желанию) свой домен**
   - Pages → *Custom domains* → например `foto.вашдомен.ru`.

## Ограничения и заметки

- **Открытый доступ.** Загружать и скачивать может кто угодно со ссылкой.
  Единственная защита — админка для удаления мусора. Ссылку давайте только гостям.
- **Тип файлов** — только `image/*` и `video/*` (проверяется на сервере).
- **Большие видео** режутся браузером на части по 88 МБ (лимит тела запроса
  у Pages на бесплатном плане — 100 МБ).
- **«Скачать всё»** — архив собирается на лету, без сжатия. CRC32 считается на
  CPU воркера; на бесплатном плане очень большой архив (десятки ГБ) может не
  досчитаться. Тогда: Workers Paid ($5/мес) или скачивать файлы по одному
  (кнопка «Скачать» в галерее работает всегда).
- **Превью для видео** генерируется в браузере; для некоторых кодеков (HEVC с
  iPhone на некоторых устройствах) кадр снять не удаётся — в галерее тогда
  плитка-иконка, сам файл загружается и открывается нормально.
- **Хранение** бессрочное, пока существует бакет. Бесплатный лимит R2 —
  ~10 ГБ хранения; сверх того ≈ $0.015 за ГБ в месяц, за скачивание Cloudflare
  не берёт ничего.
